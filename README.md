# Integrative Ensemble Modeling reveals RNA conformations targetable by small molecules

This repository contains the analysis notebooks and processed data associated with the manuscript

*Integrative Ensemble Modeling reveals RNA conformations targetable by small molecules*

The repository includes notebooks used to generate the analyses and figures presented in the paper together with the processed datasets required to run them.

## Data

The `data` directory contains processed datasets stored as pickle files. These include the quantities used throughout the manuscript (reweighted ensembles, PCA projections, SiteMap scores and other processed data).

Raw molecular dynamics trajectories and simulation input files are available separately on Zenodo due to their size.
Simulation input files (GROMACS and PLUMED), trajectories and processed data are available at:

**Zenodo:** 10.5281/zenodo.21352447
